# Engineering Roadmap

This document outlines planned enhancements, research initiatives, and architecture milestones.

---

## 🚀 Version 1.3.0 (Q1 2027)

- **Interactive CTF Challenge Room**: Terminal-driven capture-the-flag security puzzle with encoded hash flags and buffer overflow simulations.
- **WebGPU Shader Exploration**: Upgrade Three.js renderer to experimental WebGPU nodes for compute-driven particle simulations.
- **Live GitHub Activity Heatmap**: Interactive 3D block representation of daily commit volumes and pull requests.

---

## ⚡ Version 1.4.0 (Q2 2027)

- **Client-Side Edge AI Inference**: In-browser local LLM inference powered by WebLLM / ONNX Runtime Web.
- **Dynamic Threat Radar**: Real-time simulated global attack vectors mapped onto the 3D globe.

---

## 🌐 Version 2.0.0 (Long-Term Vision)

- **Multiplayer Cyberspace Hub**: WebSocket-driven presence enabling visitors to view concurrent peers exploring the portfolio canvas.
- **Encrypted Guestbook**: Ed25519 signed visitor greetings with cryptographic verification.
