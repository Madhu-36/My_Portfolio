# Cyberpunk Design System & Styleguide

This document defines the visual identity, color tokens, typography scales, and component guidelines used throughout the portfolio.

---

## 1. Typography

- **Display Headings**: `Clash Display`, sans-serif (Fontshare CDN)
  - Used for large hero text and section titles (`font-display font-bold`).
- **Body & Prose**: `Inter`, sans-serif (Google Fonts)
  - Balanced reading typography for descriptions and paragraphs.
- **Code & Terminal**: `JetBrains Mono`, monospace (Google Fonts)
  - Used for the terminal emulator, live telemetry HUD, tech badges, and ASCII banners.

---

## 2. Core Color Tokens

| Token Name | Hex Code | Purpose |
| :--- | :--- | :--- |
| **Ink Canvas** | `#05060a` | Deep cyberspace background |
| **Cyan Primary** | `#22d3ee` | Primary cyber accent, links, and glow effects |
| **Neural Violet** | `#8b5cf6` | AI and neural engineering indicators |
| **Gold Amber** | `#f59e0b` | Systems architecture, warnings, and verified badges |
| **Emerald Signal** | `#10b981` | Safe operational states and hacker mode accents |

---

## 3. Component Standards

- **Buttons**:
  - `btn-primary`: Cyan gradient with dark ink typography.
  - `btn-ghost`: Translucent ink border with hover border glow.
- **Cards**:
  - `card card-hover`: Dark ink container with subtle border-ink-800 and hover border-accent-500/40.
- **Badges**:
  - Supported variants: `accent`, `ghost`, `gold`, `gold-glow`, `neural`, `emerald`.
